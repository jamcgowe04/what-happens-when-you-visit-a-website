# Reflection

One of the most important decsions I made while working on this project was making the choice to create an interactive website that's educational. My goal was to build something that relates to computing and web development while also creating something that someone may find useful in learning about the technical processes in browsing the internet.

I used HTML, CSS and JavaScript because they pimarily worked the best in building this website from the ground up. I was also very excited about being to apply it's dark blue circuitry theme in the brainstorming phase becasue it reflects the subject matter. Since the project explains communcation between browsers, DNS, and servers, I wanted the appearance to reinforce that theme.

I think another important decision I made was planning a milestone through each week and have a task to tackle but leave room for improvement and continue to leave my mind open for additional ideas.



The most satisfying part of building this web project was laying the foundation for what I wanted my website to exactly look like. As soon as I had the theme and organization in place, it was nice to look at and I could go in and refine things as I needed to off of that foundation.

The transition from what was built in Project 01 to Building Project 02 was also rewarding. instead of adding more content, I wa sabelt o identify those areas that needed improvement and make those changes that directly addressed them.

Most importantly, deploying the project and seeing my finished work went well becasue it allowed me to share what I have built and learn the entire process in building a website from the point of brainstorming ideas to a fully finished product that anyone can take a look at.



If I were to do this project differently, I'd spend more time on the visual layout and interactive features before beginning the developmental phase. Althought building in increments worked well, having a clearer design plan earlier could have reduced the number of adjustments that were needed to make later.

I would plan the JavaScript Structure more carefully from the beginning. As I needed to add more features in project 02, certain sections of my code needed to be removed or updated to prevent duplication of content and unexpected behavior. 

In terms of tools, I would consider using a visual design tool in the process to map out the user flow before beginning to code. VS code and GitHub could still be used becasue they provided the development to be straightforward.



My takeaways from this project is learning that developing a website is much more than just writing code. It required much planning, problem solving, testing, revising, and thinking outside of my own persoective and how someone else would be able to interact with the finished product.

 I gained a better understanding JavaScript as a whole with the little to no experience I had prior to building this web project. It helped me learned how important it was to test features after making changes and be very careful in writing your code becasue one typo can effect the display of my website.

 My biggest takeaway was the value of iteration. Project 01 didn't need to be perfect and primarily it was to lay a foundation. Evaluating what worked, identifying weaknesses, and improving those areas in Project 02 helped in producing a more complete experience.

 Overall, this project strengthend my confidence in bulding web applications. Though I've built previous applications in the past, this one definitley put my skills to the test and that even a relatively small project like this one can involve technical challenges, meaningful decisions, and oppurtunities to strengthen my learning. It also gave me a foundation I can build upon for future projects.


# What Happens When Visiting a Website?

## Description
This an interactive website expirience that explains what happens behind the scenes when a user enters a URL and visits a website. When a URL is entered a step by step process is displayed and goes through the different processes involved when your browser reaches a URL. This project presents the technical concepts in a simple and approachable way for users who aren't familiar with web technologies.

## Purpose

The Purpose of this project is to give an easier understanding on the process of visiting a website. Websites are interacted with by people everyday without neceescarily kwnowing what really happens between entering a URL and seeing a webpage appaear. This wesbite breaks down this process into easy steps to review so that students, beginner web developers, and anyone interetd in learning how the web works can explore it interactviely.
